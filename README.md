# Java Recipe Manager

Desktop application for managing recipes, built with Java Swing and SQLite.

## Features

- Add new recipes
- Edit existing recipes
- Delete recipes
- Search recipes by name and ingredient
- Add ingredients with quantity and unit
- Organize recipes by category
- Mark recipes as favorites
- Display recipes as cards
- Input validation

## Technologies

- Java
- Swing
- SQLite
- JDBC
- NetBeans

## Prerequisites

- Java Development Kit (JDK)
- NetBeans IDE
- SQLite database support
